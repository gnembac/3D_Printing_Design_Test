## Notes

- Mark unavailable information as `k.A.`, assumptions as `ASSUMPTION`,
  derived/non-measured values as `estimated`.
- Keep this to one page. If more than one factor must be varied to explain
  the result, promote it to an experiment using
  [`experiment-protocol-template.md`](experiment-protocol-template.md).
