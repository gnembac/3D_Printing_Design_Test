## Report structure

1. Hypothesis
2. Objective / response variable
3. Test setup
4. Factors and levels
5. Raw data (link, never inline-edited)
6. Graphical analysis
7. Statistical analysis (descriptive vs. inferential, clearly separated)
8. Uncertainties and limitations
9. Result
10. Concrete design rule
11. Recommendation for the next experiment cycle
