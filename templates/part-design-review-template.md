## CAD check

- [ ] All dimensions defined
- [ ] Critical tolerances marked (CTQ)
- [ ] Adequate radii at loaded transitions
- [ ] Wall thicknesses printable
- [ ] Holes, threads, snap features suitable
- [ ] Overhangs and supports acceptable
- [ ] Load direction known
- [ ] Print orientation defined
- [ ] Material choice justified
- [ ] Shrinkage considered
- [ ] Warping risk assessed
- [ ] Sealing/bearing/fit surfaces adequately dimensioned

## Mesh check (for STL/3MF export)

- [ ] Manifold / watertight
- [ ] No self-intersections
- [ ] No open edges
- [ ] Correct normals
- [ ] No degenerate triangles
- [ ] Correct unit (mm)
- [ ] Correct scale
- [ ] Correct orientation
- [ ] Plausible file size
- [ ] Part ID and revision correct in filename

## Slicer check

- [ ] All layers previewed
- [ ] Wall lines complete, no unintended gaps
- [ ] Infill-to-perimeter bonding checked
- [ ] Bridges and overhangs checked
- [ ] First layer checked
- [ ] Supports checked for removability
- [ ] Estimated print time plausible
- [ ] Material consumption plausible
- [ ] Print profile versioned
